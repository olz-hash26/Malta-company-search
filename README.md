# Malta Company Search SEO landing page

A lightweight static SEO landing page targeting Malta company search, Malta business lookup and Malta company information keywords. It directs visitors to [maltacompanysearch.com](https://maltacompanysearch.com/) and is not a separate company-search product.

## Deploy

The site is configured for GitHub Pages using the workflow in `.github/workflows/pages.yml`. Open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.
